# Task 2 - AI Student Assistant

## Project Overview
An interactive student assistant web interface built using HTML, CSS, and JavaScript.

## Features
- Interactive chat interface
- Suggested questions
- Predefined responses for common student questions
- Loading indicator
- Responsive design
- Input validation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Note
This version uses predefined responses and does not connect to a live AI model.
