# Task 3: Python for AI Applications

## Project Overview
A Python-based text processing application developed as part of the Growfinix internship.

## Features
- Accepts text from the user
- Counts total words
- Counts unique words
- Calculates word frequency
- Displays results in JSON format

## Technologies Used
- Python
- JSON

## How to Run
Run `text_processor.py` using Python and enter text when prompted.
